# 🤝 Trust – Charity & Donation Website

A simple and clean **Charity / Trust website UI** built using **HTML and CSS**.  
This project focuses on page layout, sections, icons, and basic styling for a non-profit or trust-based website.

---

## ✨ Features
- Navigation bar with menu links
- Hero section with call-to-action
- Services / causes section
- Volunteer image gallery
- Countdown / donation section
- Upcoming events section
- About & social media footer

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome Icons
